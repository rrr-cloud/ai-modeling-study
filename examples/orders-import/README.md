# orders

注文データを扱う小さなライブラリです。

- テスト: `python -m unittest -q`
- Python 3.11 以上、標準ライブラリのみ

## 注文CSVの取り込み

```
python -m orders.import_csv <CSVのパス> <DBのパス>
```

- DB ファイルは先に用意しておきます（無いときはエラーになり、新しく作りません）
- 不正な行はスキップし、行番号と理由を標準エラー出力に出します
- status が `cancelled` の注文は取り込みません（対象外）。すでに DB にある注文も、消さず、上書きもしません
- 最後に、取り込んだ件数・スキップした件数・対象外の件数を出します
- 終了コード: 0 = 取り込んだ（スキップした行や対象外の行があっても 0）、1 = ファイル全体のエラーで 1 件も取り込んでいない
- 詳しい仕様は `spec.md` にあります
