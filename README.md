# AIに「作って」と頼んだら、ここまでできる。

Claude Code × Blender MCP を例に、AI駆動開発と仕様駆動開発のはじめかたを紹介する、約10分の勉強会資料です。

## 見かた

GitHub Pages で公開しています。ブラウザで開くだけで見られます（インストール不要）。

- `→` / `←` キー（またはクリック・スワイプ）で進む・戻る。項目は1つずつ出て、いま話している所が光る
- `N` キー：話す内容メモ（発表原稿）を下に出す。いま話す段落が光る
- `F` キー：全画面
- [発表原稿](script.html)：全ページの原稿。印刷もできる

## 実験について

指示A・B・C・C＋追加の修正の結果は、毎回、前の会話を知らない新しい Claude Code に指示の文だけを渡して作らせたものです（指示Aは同じ文で4回）。

- 動画の Claude Code 画面の各行は、AIが実際に行った Blender の操作1回ずつに対応しています。載せているコードの行も、AIが書いたコードからの抜粋です。
- Blender の画面は、AIの操作が1回終わるごとに自動で撮影した絵です。AIが1回の操作でまとめて作った部分は、途中の絵がありません。
- 指示Aの4回分の画像だけは、ガラスが見えるよう撮影用の照明をそろえて撮り直しています（形・材質はAIが作ったまま）。
- 「C＋追加の修正」の追加の指示は、資料の作成者が指示Cの結果を見て書いたものです。

## 中身

- `index.html` … 資料本体（外部の読み込みなし）
- `script.html` / `script-data.js` … 発表原稿（資料のメモと同じ内容）
- `videos/` … 4本の動画と、その結果の画像
- `images/` … 表紙の灯台と、その作成途中の画像
