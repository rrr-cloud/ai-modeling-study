# AIによる3Dモデリングと AI駆動開発

Claude Code と Blender MCP の実例と、仕様駆動開発の進め方を紹介する、約10分の勉強会資料です。

## 見かた

GitHub Pages で公開しています。ブラウザで開くだけで見られます（インストール不要）。

- `→` / `←` キー（またはクリック・スワイプ）で進む・戻る。項目は1つずつ表示されます
- `N` キー：発表原稿を下に表示（いま話す段落が強調されます）
- `F` キー：全画面
- [発表原稿](script.html)：全ページの原稿。印刷できます

## 資料に載せている結果について

- 指示A・B・C、時計の指示A・B・Cは、毎回、何もない状態の Blender と新しい会話の Claude Code に、指示の文だけを渡して作らせた結果です。「指示C＋追加の修正」は指示Cの続きの会話です。
- 動画の Claude Code 画面の各行は、AIが実際に行った Blender の操作に対応しています。コードの行は、AIが書いたコードからの抜粋です。
- 画像は、撮影用の照明と背景にそろえて撮っています（AIが置いた照明や床は撮影中だけ隠しています）。AIが1回の操作でまとめて作った部分は、途中の画像がありません。
- トークン消費量・操作の回数は、Claude Code が記録した値です。
- 「さらに試すとガラスのコップになることもあった」は、同じ条件で指示Aをさらに4回試したときの結果です（うち3回がガラス）。
- 「3回に分けて頼む」と「指示C＋追加の修正」の追加の指示は、資料の作成者が結果を見て書いたものです。
- GitHub Copilot の課金方式は、GitHub の発表（2026年4月27日「GitHub Copilot is moving to usage-based billing」）によります。
