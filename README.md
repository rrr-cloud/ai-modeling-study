# AIによる3Dモデリングと仕様駆動開発

Claude Code と Blender MCP の実例と、仕様駆動開発の進め方を紹介する、開発者向けの勉強会資料です。

## 見かた

GitHub Pages で公開しています。ブラウザで開くだけで見られます（インストール不要）。

- `→` / `←` キー（またはクリック・スワイプ）で進む・戻る。項目は1つずつ表示されます
- `F` キー：全画面
- `S` キー：発表原稿を別のウィンドウで開く（資料の画面にボタンは出ません）
- [発表原稿](script.html)：全ページの原稿（資料の画面には原稿やそのリンクは出ません。発表者がこのURLを直接開きます）。同じブラウザの別のウィンドウで資料を開くと、資料のページ送りに合わせて、いま話す段落に色が付きます。原稿のページから `→` / `←` キーや段落のクリックで資料を動かすこともできます。印刷もできます

## 資料に載せている結果について

- 指示A・B・C、時計の指示A・B・Cは、毎回、何もない状態の Blender と新しい会話の Claude Code に、指示の文だけを渡して作らせた結果です。「指示C＋追加の修正」は指示Cの続きの会話です。
- 動画の Claude Code 画面の各行は、AIが実際に行った Blender の操作に対応しています。コードの行は、AIが書いたコードからの抜粋です。
- 画像は、撮影用の照明と背景にそろえて撮っています（AIが置いた照明や床は撮影中だけ隠しています）。AIが1回の操作でまとめて作った部分は、途中の画像がありません。
- トークン消費量・操作の回数は、Claude Code が記録した値です。
- 「さらに試すとガラスのコップになることもあった」は、同じ条件で指示Aをさらに4回試したときの結果です（うち3回がガラス）。
- 「3回に分けて頼む」と「指示C＋追加の修正」の追加の指示は、資料の作成者が結果を見て書いたものです。
- 「完成の基準を書く」の数字は、指示Cに完成の基準を足した指示を2回頼んだ結果です（約5.45万・約5.54万、どちらも操作3回）。この2回は出来上がりの画像を撮っていません。
- 「使わない道具は読み込まない」の数字は、作業をさせずに、Blender の道具3つを読み込んだ場合（48,791）と読み込まない場合（43,181）を比べたものです。
- ポリゴン数は、指示A・指示C・指示C＋上限（「ゲームで使うので、三角形で1,000以下にして」）を頼み直し、Blender で面を三角形に直して数えた値です。ワイヤー表示の画像は、撮影のときだけ辺を見えるようにしています。
- 「AIが実際に書いたコード」は、この頼み直した指示Cで Claude Code が実行したコードの抜粋です（`...` は省略した部分）。
- 「先に質問させる」は、「コップを作って。作り始める前に、決まっていない点や不明な点があれば質問して」と頼み、返ってきた質問に、資料の作成者が指示Cと同じ内容で答えたものです。質問の文は要約しています。
- グラフと表のトークン消費量は、上の頼み直しを含む19回分です。指示Cは2回分（63,772・56,913）あります。
- 仕様駆動開発の実例（実例①〜③）は、`examples/orders-import/` のリポジトリで実際に行った記録です。人が書いたのは最初の `spec.md`（24行）と既存コード（`orders/repository.py` とそのテスト）、3回の指示（計画と質問の依頼、質問への回答、仕様変更）です。それ以外の仕様の追記・テスト・実装は Claude Code が書きました。コミットの順は `COMMITS.txt` にあります。テストの件数と10万行の所要時間（0.65秒）は、資料の作成者も実行して確かめています。差分の内容のレビューはしていません。
- まとめのページの「この資料の作成に使ったトークン」は、資料を作った Claude Code の会話の記録を集計した値です（2026-11-25 時点。合計 約1億4,785万。内訳は、キャッシュ済みの入力の読み込み 約1億4,444万、新しい入力 約278万、出力 約62万。指示ごとに頼んだ30回分の作業を含みます）。
- GitHub Copilot のクレジットの単位・単価・プランの内容は、2026年11月時点の GitHub Docs（Models and pricing、Usage-based billing for individuals）によります。
- GitHub Copilot の課金方式は、GitHub の発表（2026年4月27日「GitHub Copilot is moving to usage-based billing」）によります。

## 中身

- `index.html` … 資料本体（外部の読み込みなし）
- `script.html` / `script-data.js` … 発表原稿
- `videos/` … 4本の動画（1920×1080）と結果の画像
- `images/` … 表紙の灯台と、その作成途中の画像
- `examples/orders-import/` … 仕様駆動開発の実例で使ったリポジトリ（`python -m unittest -q` でテストを実行できます）
